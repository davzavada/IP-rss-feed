        Zotero

        Tlačítko Citace zkopíruje citaci rozhodnutí, RIS bibliografický záznam – v Zoteru pak File → Import → Import from Clipboard. Export RIS ve stavovém řádku stáhne všechny právě zobrazené položky najednou. U rozhodnutí zůstává v Zoteru doplnit senát a případně upřesnit název.
